# IMAGES AND ASSETS

Images from the reference website should be used for the new page when they are relevant to the product/content.

For images used from the reference website:

1. Identify all relevant images on the reference page.
2. Download the required images from the reference website.
3. Save the downloaded images inside:

   src/images/residental/

4. Use the downloaded local images in the new page.
5. Do NOT hotlink images directly from the reference website.
6. Do NOT leave reference-site image URLs in the final page.
7. Use the existing image naming and file-format conventions of the local project where possible.
8. Optimize images appropriately if the project already has an image optimization process.
9. Update the page/component to reference the local image path.
10. Verify that every image loads correctly.
11. Make sure the images are responsive and fit the NEW WEBSITE'S existing design.

IMPORTANT:

The reference website is the source for the product/content images.

The local project must use local copies of those images.
